# ADR-0004 世界模型：多层格子 + 信息版本 + 势能驱动

- 状态：已接受
- 日期：2026-10-26
- 相关：W1 / W3 / W4 / D1 / T1

## 背景

需要一个既让信息在空间中有形状、又能自行演化、还能回放的世界模型。候选方案（自由 JSON、图、ECS）缺少空间语义，或无法表达"信息差驱动"。

## 决策

1. **空间**：多层二维矩形格子，层即高度，格即坐标。每格一张按逻辑时间排序的信息表；地形（墙）按格存，带通道渗透率 `{move, opacity, acoustic, scent}`。层间默认不连通，由数量不固定的楼梯格子建立双向垂直边。
2. **信息**：稳定 `id` + 版本链。转述保留 id、内容可变（失真）；无父版本的新 id 即造谣。内容以自然语言为主。
3. **传播**：预算衰减 `strength = s0 - stepCost×距离 - wallLoss - decay×Δ时间`，按 `距离/speed` 延迟到达；低于阈值消失。冲突由 LLM 在发射时判定，记 `supersedes`；格子机械遮蔽，不回溯版本链。
4. **动力与观测**：驱动是角色本性对信息差的反应，不是外部调度；世界不计算势来决定谁行动。势 `V(a) = Σ W(a,b) · Σ_{id∈sub(a)} d(...)` 作为观测量，判断世界仍在演进还是已热寂。空间扩散是同一势在物理通道上的泄流，角色行动是它在认知通道上的泄流。
5. **推进**：回合制并发——并发宣告、统一结算，回合不是时钟（见 ADR-0007，取代本条原"事件队列 + 静止点"）。
6. **派生与记账分离**：格子场是每结算重算的派生视图；编年史只记源、判断与行动。

## 候选

| 方案 | 取舍 |
|---|---|
| 自由 JSON 文档 + patch | 回放简单，无空间语义，信息差无法表达。否决 |
| ECS / 图 | 查询强，回放与工具面复杂，当前规模不值得。否决 |
| tick 驱动 | 世界被 LLM 延迟拖慢，与"信息差驱动"不符。否决 |

## 后果

- 正：一条"势差 × 通道通透性 → 流"的定律同时解释扩散与行动；回放只依赖已记录的事件。
- 负：世界没有全局真相；冲突判定依赖 LLM，可机械校验的不变量减少；静止点可能不出现，需要冷却或配额。
- 约束：扩散循环里不得调用模型，否则成本与地图面积成正比。

## 待验证

格子表重算的规模上限；静止点是否可达；遮蔽导致旧事实"复活"是否可接受。
