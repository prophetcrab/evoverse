# ADR-0006 角色模型：状态/信息二分、三阶段环、两类寿命

- 状态：已接受
- 日期：2026-10-26
- 相关：D3 / D4 / W3 / W4

## 背景

角色既是世界的观察者，也是行动者。需要一个足够小的数据模型：世界能拿它做计算，模型能拿它做判断。

## 决策

1. **两类数据**：状态（机器可读，决定能做什么）与信息（版本集合，决定想做什么）。势算在信息上，动作空间由状态约束。
2. **行为环**：`feeling`（读本地信息差 → 订阅、`remember`）→ `thinking`（产出版本：转述、捏造、私念）→ `acting`（`speak` 空间扩散 / `tell` 定向 / 改变状态）。一个环 = 一个 turn，三阶段 = 三个 step，工具集按阶段切换。
3. **状态到信息的桥**：状态经"表现"渲染成信息，角色可以覆盖表现以隐瞒或伪装。表现不等于状态。
4. **两类寿命**：事件型信息（说话、动作）按 TTL 过期，像水波；状态型信息（地形、外观）由状态每结算派生。不可逆残迹是长 TTL 的事件型条目，与当前外观叠加。
5. **唤醒与休息**由角色自身处境决定（本地有新信息、自身状态变化、未完成的念头），世界不调度。势与活动率只用于观测。

## 候选

| 方案 | 取舍 |
|---|---|
| 单一"角色状态"包 | 简单，但可计算部分与可读部分混在一起，势与动作空间无法分开约束。否决 |
| 纯数值需求驱动 | 易计算，但与"思考交给 LLM"冲突。否决 |
| 状态 / 信息二分 | 世界算它的、模型想它的；代价是两套存储与同步。接受 |

## 后果

- 正：势与动作空间各有明确载体；内心与公开行为有清晰边界，利于解释与涌现度量。
- 负：状态与信息需要靠表现层同步；记忆不设寿命（短周期够用），长期运行会无界增长，届时才需要遗忘策略。
- 待验证：`speak` 与 `tell` 的痕迹差异；思考条数上限；小场景下的上下文规模。
