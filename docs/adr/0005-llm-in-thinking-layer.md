# ADR-0005 思考层交给 LLM，判断落成事件

- 状态：已接受
- 日期：2026-10-26
- 相关：R1 / S1 / S2 / W3 / W4

## 背景

早期方案倾向把冲突检测、相关性、规则都做成固定规则或 DSL，以换取可计算性与静态校验。这会把世界的语义结构写死在设计者的键与语法里，与"自演进"冲突。

## 决策

- **判断类工作全部由 LLM 完成**：事实冲突、转述失真、规则是否成立、涌现是否发生。结果与理由作为事件记录。
- **不要求**事实键化、不要求 DSL、不要求静态校验。规则是自然语言描述。
- **回放只重放已记录的判断**，不重跑模型。这是"思考层交给 LLM"成立的前提。
- **调用预算**：LLM 调用量与社会事件成正比，不与格子数、条目数成正比。因此判定必须发生在"说出/触发"的时刻，不能进入扩散循环。

## 候选

| 方案 | 取舍 |
|---|---|
| 键化事实 + LWW | 冲突可机械计算，但事实结构由设计者预设，语义表达受限。否决 |
| DSL + 静态校验 | 审批可自动化，但规则表达受限、P4 的规则修改不自然。否决 |
| 自然语言 + LLM 判定 | 表达自由、贴合 P4；代价是审批依赖评审模型质量。接受 |

## 后果

- 正：角色可以用语言提出与修改规则；解释里带理由，而不只是键相等。
- 负：影子世界失去"无矛盾"这类机械不变量；每次判断有推理成本与延迟；P4 审批退化为 LLM 评审 + 反例库。
- 约束：同一批判定应尽量在同一轮推理内完成（如主题提取与冲突声明），避免为拆解而多付调用。
