## 核心前提

- 动力不是 tick、不是剧本事件、也不是外部调度机制：信息差是角色本性上的驱动力，势能是它的观测量（D1）。世界是否还在演进、是否已热寂，由势与活动率观测。
- 演化方向不可预测但并非随机：每条分歧都能追到知识的不对称和某次行动，世界规则内不掷骰子。
- 事件与逻辑时间只是记账与坐标：物理过程按时间衰减、按速度延迟到达，没有全局节拍。
- LLM 判断一律落成事件；回放只重放事件，不重跑模型。这是"思考层交给 LLM"能成立的前提。
- LLM 调用量必须与"社会事件"成正比，不与格子数、条目数成正比——否则地图一大就崩。
- 执行模型是回合：所有愿意行动的角色并发宣告，统一结算后进入下一轮。回合不是时钟——没有愿意行动的角色就没有下一轮。
- 信息有稳定 id、可失真（W4），空间损耗按载体不同（W3）。

下一步顺序：W2 / A1（P1 开工前）→ M1 / G1 / 唤醒休息（P3 前）→ S1 / S2（P4 前）。D2 的目标归属已由 D4 部分回答，剩余是目标如何生成。

当前范围：小场景、短周期。长周期问题——记忆遗忘、存储增长、热寂观测窗口——一律推迟。

## A1 插件拆分粒度

候选：单包多子插件 / 多包 / 先单包后评估
倾向：先单包
理由：Cordis 的组合单位是插件而非包，拆包随时可做；拆包成本立刻疼。
待定：子插件是否各自 `inject`，还是总 `apply` 统一注入。

## W1 世界状态模型

候选：自由 JSON 文档 / ECS / 图 / 多层二维矩形格子
倾向：多层二维矩形格子——层即高度，格即坐标，每格一张按逻辑时间排序的信息表；实体带坐标；地形单独存
理由：空间是涌现的主要载体（距离、遮挡、信息不对称）；格子寻址使扩散与感知成为纯函数，回放成本低；比自由 JSON 有结构，比图便宜。
待定：格内多实体还是单实体；各层尺寸是否必须一致；地形能否被规则改写。

## W2 编年史存储形态

候选：内存数组 / JSONL / SQLite / 复用 `ctx.sessions` 事件流
倾向：P1 内存数组，P2 起 JSONL
理由：回放只需顺序读；SQLite 与 session 复用先验证再换。
待定：`ctx.sessions` 的隔离语义能否支持"多会话、单全局编年史"（若能，方案 4 最优）。

## W3 扩散与感知语义

前提：每格信息按策略向邻格扩散；地形（尤其墙）按载体不同产生不同损耗。以下为默认取舍，待拍板。

- 条目：`{ kind, strength:int, versionId }`。强度必须存在且为整数，否则扩散退化为布尔洪水（若干次结算后全图皆有），浮点衰减会让回放哈希不稳。
- 合并：同格同 `(kind, versionId)` 取 max（重发即刷新，不无限叠加）；不同版本并存。
- 两类寿命，存储路径不同：
  - **事件型**（说话、动作、声响）：产生即扩散，按 TTL 过期并衰减，过期后从所有格子消失，像水波。空间寿命短，但被角色 `remember` 后随记忆继续存活。
  - **状态型**（地形、实体外观）：不单独发射，每结算由状态派生，状态在则在。不可逆改变的残迹（断墙、血迹）例外——它是长 TTL 或 ∞ 的事件型条目，即使后来修复了也留着。当前外观与残迹叠加。
- TTL 按回合计：1 回合 = 存活到下一轮结算前。"本轮存活"即 TTL = 1。
- 每格一张按逻辑时间排序的信息表。冲突由 LLM 判定，以 `supersedes: versionId[]` 落在发射事件上；格子按声明机械遮蔽。判定发生在"说出"的时刻，不在"到达"时刻——放进扩散循环会让调用量与格子数成正比。
- 覆盖是读路径上的视图，不改写历史：版本链不可变，旧条目仍留在表内但被遮蔽。副作用是旧事实会在新说法衰减消失后重新可见（"复活"）——接受它为真实，或加 tombstone / 撤回事件才能压住。
- 表是每结算从源重算的派生视图；把表当唯一真相会让每步写入数万行，编年史爆掉。
- 传播预算（取代固定半径）：`strength = s0 - stepCost(kind)×距离 - wallLoss(kind, 地形) - decay(kind)×Δ逻辑时间`，低于阈值即消失。半径是算出来的，不是配的——"声音够响就传得远"自动成立。
- 传播速度：`到达时间 = t0 + 距离 / speed(kind)`，感知只看到到达时间 ≤ 当前逻辑时间的条目。视觉与声音在我们的尺度近乎瞬时；速度只在大尺度或慢通道（气味）上制造"消息还没到"的延迟。
- 由此，信息差主要来自**衰减与遮挡**（地方性知识），不是延迟；真正慢的是口口相传（W4 的转述，速度 = 角色行动速度）。
- 墙在格子上，不在格边上：连续墙格数即墙厚，损耗按穿越次数累加，厚度自然体现。
- 地形每格带通道渗透率 `{ move, opacity, acoustic, scent }`（1 = 全通，0 = 全阻），损耗 = base(kind) × (1 - 渗透率)。同一套属性顺带表达门（move 通、opacity 阻）与窗（move 阻、opacity 通）。
- 视觉里再分两类：**在场**是状态型（按位置与表现派生，按观察者做视线判定，不发射、不记事件、无 TTL；移动后旧格自动消失）；**动作与表情**是事件型（发射、有 TTL、可扩散）。
- 视觉走视线判定：观察者到目标的直线若穿过 `opacity = 0` 的格则不可见，视觉不做扩散。声音、气味走扩散并按渗透率衰减。
- 感知不产生版本；`remember` 是产生或引用版本的唯一入口，否则每看一眼都会写一条日志。
- 权威表示：源列表（带 ttl，可 ∞）为准，每格场每结算由源重算；派生场不进编年史，回放时重算。否则每结算数万条格子写入会把编年史撑爆。
- 更新：同步双缓冲，按 (layer, y, x) 固定顺序。
- 层间默认不连通，通过楼梯格子连接，数量不固定。楼梯格本身是 location，声明一条到相邻层的双向垂直边 `(L,x,y) ↔ (L±1,x,y)`，目标格须可行走；不需要单独的 portals 表，垂直边由地形派生。
- 垂直边的传播：在通道渗透率之外再乘一个垂直系数——声音默认可上传但有额外损耗，视觉默认阻断（站在楼下看不见楼上），除非是开放天井（`opacity` 通）。
- 传播是另一套机制（版本链见 W4），不共用数据结构。

**参数（初版）**：强度 0..1000 整数；可察觉阈值 50，可辨认阈值 300。低于可察觉即不可见/不可闻；介于两者之间只能得到模糊描述——这正好是失真的入口（W4）。

| 通道 | 每格损耗 | 墙损 | 速度 | TTL |
|---|---|---|---|---|
| 视觉 | 80 | `opacity = 0` 硬阻断；否则 `400 × (1 − opacity)` | 同轮到达 | 1 回合 |
| 声音 | 50 | `600 × (1 − p)` | 300 格/回合（室内即瞬时） | 1 回合 |
| 气味 | 100 | `400 × (1 − p)` | 3 格/回合 | 4 回合 |

发射初值：低语 250 / 正常说话 600 / 喊叫 1000 / 动作与表情 800 / 强气味 700 / 残迹 700（TTL = ∞）。

地形渗透率默认值：

| 地形 | move | opacity | acoustic | scent |
|---|---|---|---|---|
| 墙 | 0 | 0 | 0.3 | 0.4 |
| 门（关） | 0 | 0 | 0.6 | 0.7 |
| 窗 | 0 | 1 | 0.8 | 0.9 |
| 空地 | 1 | 1 | 1 | 1 |

验算：喊叫隔一堵墙剩 530（可辨认），隔两堵剩 60（只能察觉有声音）；正常说话隔一堵剩 130（听不清内容）；低语隔墙归零。视觉满分 11 格可察觉、8 格可辨认。

垂直：过楼梯边的损耗按 `3 × 每格损耗` 计；视觉默认阻断，开放天井（`opacity = 1`）例外。

**楼梯格状态**：`open` / `blocked` / `destroyed`，对应操作 打开、堵住、拆毁、修复。`open` 可通行、垂直边存在；`blocked` 不可通行但声音部分上传（`acoustic 0.3`）；`destroyed` 垂直边不存在，两层彻底断开。三种变更都是地形改写，进编年史。

推迟（短周期不设遗忘）：角色记忆不设寿命；单次运行超出上下文预算时再解冻。

待定："本轮"是否需要成为显式单位（倾向不需要，TTL 足够）；主题标签由 LLM 在发射时提取（与冲突判定同一次推理，不额外调用）；冲突判定由发射方自述（免费，但说话人自有立场）还是独立仲裁者（准确，每次发射多一次推理，倾向 P2 前者、P4 起可配后者）；半径 0 且不衰减的原地痕迹是否与瞬时场同一表示（倾向同一：ttl=∞ 的源）；全图重算 vs 增量扩散（倾向全图，规模在 10^5 格内可忽略）；地形被规则改写时如何记录（地形是主状态，变更须进编年史，扩散拓扑随之变化）。

## W4 信息身份、版本与失真

机制：信息有稳定 id；角色感知后向外转述时 id 不变、内容可变（谣言）。

- 两层表示：`Info{id, kind, origin}` 是身份；`Version{versionId, infoId, content, derivedFrom?, holder, at}` 是某一次说法的内容（`at` 为逻辑时间）。id 回答"这是不是同一件事"，版本回答"这一次是怎么说的"。
- 场引用版本而非 id：扩散的是具体说法，同一 id 的多个版本可同时在地图上流通，这正是谣言竞争。
- 转述是输入事件，进编年史。失真不能在回放时重新生成（LLM 输出不可复现），必须记录成版本数据——这不违背"派生不进编年史"。
- 感知返回强度达阈值的版本；"订阅"是显式动作 `remember(versionId)`，写入 `agentKnowledge[agentId]`。自动订阅会撑爆上下文，也会丢掉"谁在何时听说"的因果。
- 造谣与转述分开：新 id 且无父版本 = 造谣；同 id 加 `derivedFrom` = 转述。两者都合法，lineage 自动区分。

`content` 以自然语言为主，不要求键值 schema：冲突由 LLM 提取（W3 的 `supersedes`）。代价要认——失真距离不再能机械计算（需 LLM 或向量相似度），影子世界也无法机械校验"无矛盾"这类不变量。
待定：同格同 id 多版本时感知是全部返回还是"最强版本 + 另有 N 种说法"（倾向后者，本身就是谣言市场的叙事）；版本是否带可信度；失真度用什么度量（LLM 判定 / 向量距离 / 不度量）。

## T1 推进机制（回合制并发）

方向：一轮 = 所有愿意行动的角色并发宣告 + 统一结算；结算完进入下一轮。

- 角色基于轮初快照行动，效果在结算时统一应用。否则后行动者会看到先行动者的结果，"并发"变成"先到先得"。
- 回合不是时钟：无人愿意行动则世界停止，不空转。
- 结算顺序确定：按行动优先级排序，同值按 id。冲突（同一目标的不兼容行动）在结算时裁决，不调模型。
- 信息在结算后可见：第 N 轮说出的话在第 N+1 轮被感知；TTL 以回合计。

待定：慢角色的行动推迟到下一轮还是丢弃（倾向推迟并标记迟到）；空转角色如何判定不参与本轮（倾向本地无新信息即不下场）；行动优先级是否作为角色状态字段（倾向是，如速度或先手）。

## T2 回放与确定性

方向（待拍板）：

- 回放不重跑 LLM，把记录的 agent-action 与 LLM 判定当既定输入；
- `fastReplay` 直接重放事件；`verifyReplay` 重算确定性部分（扩散、势）并校验状态哈希，LLM 判定不重跑；
- 确定性计算（扩散、势）禁止读 wall clock、禁止未种子随机；LLM 判定不受此约束，但必须记录；
- 事件序是全序：异步 agent 的行动按到达顺序记录；`verifyReplay` 只校验规则确定性与派生场重算；
- 事件带 `causedBy` 边，构成因果 DAG。tick 取消后，这是唯一的解释单位——"世界怎么变成这样"是指着因果链回答，不是指着时间片。
- 编年史必须记录规则集版本，否则 P4 改规则后旧结算回放失真。

待定：`fastReplay` 与 `verifyReplay` 的实现成本；LLM 判定无法被机器复核，`verifyReplay` 的能力边界要写清。
反事实推演（"如果当时换决定"）列为非目标。

## R1 规则本体（核心）

候选：自然语言规则 + LLM 判定 / 声明式 DSL / 代码函数
倾向：自然语言 + LLM 判定，判定结果与理由记录成事件
理由：与"思考层依赖 LLM"一致；规则可被角色用普通语言提出与修改，P4 更自然。代价：每次触发一次推理、无法静态校验、回放只能重放已记录的判定。
待定：规则触发频率与调用预算（触发过密会压垮成本）；没有静态校验后 P4 的自动审批靠什么站住（倾向 LLM 评审 + 反例库 + 记录理由）。

## R2 规则管线分发模式（已降级）

tick 取消、规则改为事件触发的 LLM 判定后，不存在"每个结算跑一遍的全局管线"，Cordis 的分发模式不再构成设计问题。只剩实现细节：多条规则反应同一事件时如何取用事件数据。

## R3 规则冲突与执行顺序

候选：显式 `priority` / 注册顺序 / 冲突检测拒绝本次反应 / 后写覆盖
倾向：`priority`（缺省 0）+ 注册顺序；同字段多次写入允许多记录、后写覆盖
理由：拒绝整次结算会因一条规则卡死世界。
待定：一次结算结束时是否输出规则反应摘要。

## G1 角色与 agent 会话绑定（成本关键）

候选：一角色一真实会话 / 一会话扮演多角色 / 混合（关键角色真实，背景角色模拟）
倾向：混合；P3 先实现"一角色一真实会话"验证机制
理由：群体规模靠模拟撑起，否则每个角色每次唤醒都是一次完整推理。
源码已核实（未运行验证）：可向运行中会话投递输入——`agent.send(message,target,wakeup)`、`followup`、`steer`（唤醒）、`inject`（不唤醒），边界分 `next-step` / `next-turn`（`core/agent/src/runtime-types.ts:244-270`、`agent-loop/src/inbox.ts`）。原"最大风险"解除。
待定：绑定可否热切换（模拟 ↔ LLM）；上下文压缩方案（是否复用 compaction seam）。

## G3 角色的唤醒与休息

候选：世界每个结算唤醒每角色 / 角色按势能变化唤醒 / 角色自由节奏
倾向：角色按本地变化自唤醒——有新信息进入所在格、自身状态变化、或有未完成的念头；动不动由角色自己判断
理由：V 不参与调度。角色感受到的就是本地信息差，那就是 feeling 的输入，世界不需要额外注入。
待定：休息条件（多久没有本地变化算闲下来）；防抖与冷却；高势而久不动是否需要观测告警（停滞，而非热寂）。

## M1 模型分层

四类调用者：角色 agent / 背景角色模拟 / 元层（提案生成与审批）/ 涌现判定器
倾向：角色用 `deepseek-flash`；关键角色用 `deepseek-v4-pro` 并按角色固定；背景角色不调 LLM（规则/模板）；元层与判定器用 `v4-pro` 且与角色会话隔离
理由：成本 = 每 step × 角色数；真正的开销是每步注入的世界切片，不是模型单价，1M 上下文不等于免费。
待定：审批器与提案者是否必须异源（同源易共谋）；flash 的 `toolUpdate: 'addition-only'` 对 P4 动态工具集意味着什么。

## M2 模型选择粒度

候选：按角色固定 / 按结算切换 / 按 step 动态切换
倾向：按角色固定；需要更强模型时整角色升级
理由：`ModelSelection` 是 step 级生效且写入会话日志（`core/agent/src/runtime-types.ts:54-71`），但会话内换模型会让行为归因与回放解释变弱。
待定：是否允许"单次升档"例外（倾向不允许）。

## D1 信息势与泄流（引擎，核心）

假设：两个 object 之间的信息差产生势能，世界沿势能梯度演化——不可预测，但不含随机。

- 势：`V(a) = Σ_b W(a,b) · Σ_{id ∈ sub(a)} d(Ka(id), Kb(id))`。`W` 是社会通道通透性（是否认识、能否说话、亲疏），`sub(a)` 是 a 当前关注集，`d` 是版本差（同版本 0、一方缺失 1、版本不同为内容距离）。
- 关注集不是过滤函数，是检索性订阅：角色每次运行时依人设与上下史更新订阅，订阅本身作为事件记录。首次订阅由人设生成。`subscribe` 与 W4 的 `remember` 配对——前者声明关心什么，后者记录学到了什么。
- 订阅不是独立机制，而是 feeling 阶段的一部分（D3）。
- 与 W3 同构：空间扩散是同一势在物理通道上的泄流（流量 ∝ 强度差 × 地形渗透率），角色行动是它在认知通道上的泄流（通透性是 W）。一套定律，两种泄流。
- 不接线：世界不计算 V 来决定谁行动。角色动是因为它自己的处境——feeling 读到的本地信息差、自身状态、未完成的念头。把 V 接到调度上，世界就被一个角色看不见的力量编排，与"驱动是自身特性"矛盾。
- V 是观测量，不是点火器：用于判断世界还在演进还是已经热寂。热寂 = V 长期趋零；停滞 = V 高但活动率低（有人有动机却没动）。两个量一起看。
- 流向可以是弥合也可以是制造差异：依赖信息优势的角色会主动增大 V（隐瞒、造谣），依赖合作的角色会减小 V（告知、求证）。符号的混合是不可预测性的来源。
- 不可预测 ≠ 随机：规则内禁用 RNG，全部分歧可追到 K 的不对称与某次行动。
- 热寂风险：若所有角色只弥合差异，V→0 后世界静止。必须有不平衡源——行动本身产生新版本、目标永不满足、部分角色靠信息优势获利。

待定：关注集规模上限（不设限会订阅一切、烧穿上下文）；检索底层用结构化主题索引还是向量（倾向结构化；向量依赖模型版本，除非缓存结果）；`W` 是否随关系演化；活动率的度量窗口（按逻辑时间还是按结算次数）。

## D2 角色目标与初始设定

问题：D1 说"目标决定流向"，但目标从哪来没定。没有目标的角色只有订阅，没有动机。
候选：人设模板给定 / 世界初始配置 / 运行中自生成并记录 / 外部（玩家、导演）注入
倾向：人设给定初始目标 + 运行中可自改写，改写记为事件
理由：初始目标保证世界一启动就有势差；自改写让目标随经历演化且可回放。
待定：目标是否数值化（与"思考交给 LLM"有张力）；目标改写后旧的势如何重算。

## D3 角色行为环（feeling / thinking / acting）

每个角色的一次行为是一个三阶段环：`一个环 = 一个 turn，三个阶段 = 三个 step`。

- **feeling 感受**：读所处 location 的信息表，与自身信息（D4）做差，得到"知道自己不知道"的候选；LLM 选择订阅哪些、`remember` 哪些。这一步同时更新 `sub(a)`（D1）。
- **thinking 思考**：产出版本——可以是已知信息的转述或改写（W4 的失真就发生在这里），可以是新 id 的捏造，也可以是不打算说出口的想法。一条或多条，需设上限。
- **acting 行动**：把某些版本发布出去或作用于世界。两种发布通道必须分开：`speak` 走空间扩散（附近能听到），`tell` 是定向私语（不经空间，仍记为事件）；外加移动、取放、对环境和他人施加影响。全部走工具调用。
- **转移**：`idle → feeling → thinking → acting → idle`。feeling 无新信息则直接回 idle（只付一次便宜调用）；thinking 无行动则跳过 acting。
- **阶段工具集不同**：feeling 只读，thinking 无工具（结构化输出），acting 只写。用 step 边界切换工具集，不额外消耗模型调用。
- **感受即势**：feeling 读到的本地信息差就是角色承受的势，不需要世界另行计算与注入。

待定：每个环的思考条数上限（不设会原地空想）；thoughts 存哪里（倾向会话日志 + 有界缓冲，不进空间）；`tell` 是否也应留空间痕迹（旁听者能不能听到私语）。

## D4 角色数据模型（状态 / 信息）

角色只有两类数据，职责不同。

- **状态 state**：结构化、机器可读、世界可计算——位置、生命值（5 格）、能力状态（名称 / 等级 / 负荷 / 稳定·亢进·暴走·封印 / 代价）、持有物、需求水平、目标引用、对他人的**态度**（立场 + 一句话描述）、关系计数、关注集 `sub(a)`。变化即 patch，量小，进编年史。
- **信息 info**：角色持有的全部信息条目（版本集合）——感知到的世界信息、自己的想法、别人告诉它的说法、**关于他人的认知事实**（"少爷夜里出门"）。只增不改，带 provenance（`perceived` / `thought` / `told`）。
- **分工**：状态决定"能做什么"，信息决定"想做什么"。势 `V` 算在信息上，可用动作由状态决定。
- **对他人的三层区分**：客观交互计数（help / harm / contact，结算时机械累加，驱动 `W`）；主观态度（立场 + 一句话，角色自己每轮更新）；关于他人的认知事实（属于信息，可能记错）。
- **状态收尾**：每轮结束按"自己的记忆 + 自己的行动"更新状态——需求漂移是机械的，态度 / 关注 / 目标 / 表现由角色的一次反推出 patch，随结算写入编年史。没有行动的角色只做机械漂移。
- **桥**：状态变化只要可观察，就必须渲染成信息条目（外观、伤痕、动作），否则别人永远感知不到，世界只剩传闻。倾向在 acting 的同一次推理里顺带判定"这会被看成什么"，不额外计费。
- **目标归属**：目标的可计算部分（引用、条件）放状态，叙事描述放信息——否则 D1 的势与关注集无法计算。这同时是 D2 的初步答案。
- **信息是超集**：W4 的 `agentKnowledge` 只是其中获取来的部分；想法与听来的说法同属信息，用 provenance 区分。

待定：态度立场集合是否够用（当前五档：亲近 / 中立 / 戒备 / 敌意 / 畏惧）；关注集放状态还是由信息派生（倾向状态，便于算势与审计）；状态里哪些字段他人可观察、由谁判定（倾向 LLM 在 acting 时判定）。

## D5 行为：方向关系对 + 一次调用

一次行为 = 一个方向关系对（actor → target）+ 一次写工具调用。

- **关系对**：`Action{actor, target, label, polarity, at}`。target 可以是实体、格子（广播或环境）、或自己。`label` 是 LLM 在 acting 时给出的自由文本（"威胁""交易""警告"），外加一个粗极性 `help / harm / neutral`，后者用于聚合与度量。
- **一次调用**：acting 阶段只允许一次写工具调用；调用内部可以产生多条 mutation，但共享同一个 cause。thinking 可以产出多个候选，acting 只能选一个执行。
- **工具面**（`src/sim/tools.ts`）：`move` / `speak` / `tell`（告知 / 询问 / 请求 / 威胁）/ `attack`（徒手、推搡 1 点，武器 2 点）/ `ability`（self / other / world / info：治疗、留痕、传话）。一轮只能选一个。
- **目标必须在感知内**：看不见的实体不能作为目标，防隔墙操作；由工具层校验。
- **关系分两层**：客观交互累积成关系强度（带时间衰减），供 D1 的 `W` 使用；主观关系（"我信任他"）是角色自己的想法，存为信息，不影响 `W`。
- **行为会被看见**：观察到的行为产生事件型视觉信息（"A 打了 B"），扩散给旁人。行为本身是记录，观察是另一次信息产生。
- **闭环**：行为 → 关系 → 信息通道通透性 `W` → 谁能听到谁 → 下一个行为。

待定：关系强度的聚合方式（计数 / 加权 / LLM 判定）；一次调用内部允许的最大 mutation 数；target 为格子时受众如何解析（同格全部实体，还是按通道筛选）。

## U1 观察界面

形态：dsh 客户端面板，占用 root 作用域 `main` keyed slot（`ctx.layout.selectPanel(id)` 切入，`null` 回会话界面）。只观察不写世界——写操作仍然只走角色工具调用，避免出现第二个真相来源。

- 两种模式：**2D**（单层，按键切层）与 **3D**（等距叠层，一次看多层）。都用 Canvas 2D 绘制；3D 是堆叠平面而非 WebGL，先省掉引擎依赖。
- 角色用小光标表示，按屏幕空间定尺寸（不随缩放变小），实心 = 真实会话、空心 = 模拟角色。
- 尺寸预设：100×100 / 40×60 / 30×30 / 20×20（宽×高，每层相同）。
- 叠加层（独立开关）：三个通道的强度场、墙与楼梯状态、信息条目、关系边。
- 时间：当前回合 + 回放拖动条，可单步、暂停、跟随某个角色。
- 交互：拖拽平移、滚轮缩放、`[` `]` 切层、点击实体打开检查器、快捷键优先于按钮。

待定：数据通道（dsh Remote 还是轮询快照）；界面是否允许干预（暂停、手动推进一轮）；100×100 多层叠放的重绘策略。

初版已实现：2D/3D、四种尺寸、三通道叠加、检查器、快捷键；数据源为本地 demo 世界，尚未接 dsh 宿主。

## D6 角色初始化与行为算法

**初始条目**：每个角色 18–19 条私人记忆（不进空间、不扩散），分七类——自我 3、信条与世界观 5–7（直接约束行动方向）、世界事实 3–4、关于他人的认知事实 2–3、往事 1–2、秘密 1、传闻 2（各自与另一角色共享 `infoId`、内容不同）。全量存记忆，进提示时全量拼装（记忆、关注、反馈摘要、可感知候选都不截断）；思考产出仍限 4 条。世界侧：每个非虚空格带区域 id 与静态描述。另配：初始**态度**（立场 + 一句话，属于状态）、生命 5 格、**能力状态**（名称 / 等级 / 负荷 / 稳定·亢进·暴走·封印 / 代价）、目标 1–2、需求 3 维、客观关系初值。

**每轮行为**（所有存活角色都消耗模型调用，不再按资格筛选；死亡/失能者跳过）：

1. 全部存活角色并行进入三阶段；本地没有新条目时感受阶段跳过模型调用，思考与行动照常。
2. **feeling**（LLM，只读）：读当前格条目，按强度分"清晰/模糊"；输出 `remember(versionIds)` 与关注集更新。
3. **thinking**（LLM，无工具）：产出 0–3 条版本草稿（`content / topics / derivedFrom / supersedes`）、至多一个意图（`target / behavior / expected`），以及**状态 patch**（态度、关注、目标状态、表现）。
4. **acting**（LLM，写工具）：一次写调用（`speak` / `tell` / `move` / `take` / `use` / `give`），目标必须在视线内。
5. **结算**：按先手应用行动，同值按 id；记录关系对；机械漂移（需求、关系计数的时间衰减）；发放下轮反馈摘要。
6. **状态收尾**：应用本轮行动者的状态 patch，写进编年史；未行动的角色只保留机械漂移。

待定：初始条目手写还是由人设生成（倾向先手写，可复现）；需求取哪几维（倾向安全 / 地位 / 好奇）；反馈摘要模板化还是 LLM 生成（倾向模板，省一次调用）。

## E1 涌现如何判定

倾向：先全量记录，判定后置；判定器为可替换插件
理由：完成前无法定义涌现，中间交互不能丢。
P3 判据：协同（移除任一角色行动则结果不出现，用影子重放检查）/ 持续（模式在 ≥N 次结算中重复）。W4 上线后优先用版本数、最大偏离、传播树深度这类可计算指标，不用 LLM 判定。
待定：是否需人类确认后才入编年史；阈值取多少。

## S1 规则修改的审批者

倾向：`bail` 链——引用与语法检查 → 影子世界试跑 → LLM 评审（带反例库）→ 人类（可配置关闭）
理由：规则是自然语言，没有可编译的静态校验；能机械做的只剩引用完整性与影子试跑。
待定：演示中人类闸门是否可关（倾向可关，并写明这是信任假设）；评审模型与提案模型是否必须异源。

## S2 提案是否需要试运行

倾向：需要；影子世界 = `ctx.world` 的 fork，用提案规则跑 K 次结算
理由：世界状态是纯数据（W1），fork 近乎免费；但规则是自然语言，可机械校验的不变量有限。
待定：K 取值；不变量清单怎么来（人工维护 / LLM 从规则推导 / 只比较"不崩、不热寂"这类粗指标）。
