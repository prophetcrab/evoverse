## 已实现

- 多层二维格子；层间默认不连通，楼梯格建立双向垂直边，三态（open / blocked / destroyed）。
- 地形四类在用：地面、墙、窗、虚空（门格在生成时转为地面，墙上的缺口直接可通行），每格带四通道渗透率；虚空阻断所有通道。
- 校门规则：地面层安全边界 (2,2)–(117,77)；越过边界即死亡，尸体随机刷回安全区内，并留下一条“某某的尸体”的视觉信息。
- 两个场景：程序生成的 demo 世界，以及庄园地图上的「私立雾影学园」剧本（120×80×4，18 名能力者，12 条地图世界信息）。
- 视觉场按观察者做视线判定（Bresenham + 不透明格阻挡）；声音、气味按预算扩散，支持跨层（3× 垂直损耗）。
- 四种尺寸预设：100×100、40×60、30×30、20×20；层数随预设（3 或 2）。
- 2D/3D 双视图、层切换、通道叠加、角色与格子检查器、键盘快捷键。
- 2D 按当前层的内容范围自动取景（有虚空时）；3D 非活动层只显示墙体并按高低着色（低于当前层偏冷、高于偏暖）。
- 角色仿真：每人 18–19 条初始记忆（自我 / 信条与世界观 / 事实 / 关于他人的事实 / 往事 / 秘密 / 传闻）；信条条目直接约束行动方向，生命 5 格、能力状态（名称 / 等级 / 负荷 / 稳定·亢进·暴走·封印 / 代价）、需求三维、对他人的态度（立场 + 一句话）、目标、关注、关系计数。
- 格子位置：每个非虚空格都带区域 id（23 个区域 + 校园外围），区域表保存名称与一句静态描述；角色提示里带「所在位置」，格子检查器显示区域与描述。
- 地图世界信息：开局在具体格子铺 12 条（公告、霜、锁链声、花香、脚印等），部分长期存在（ttl 99），部分只维持几轮。
- 伤害：`attack` 徒手/推搡 1 点；`武器` 读取物品的 damage/range，需持有武器，护具按 defense 减伤。`ability` 的 self/other 治疗回 1 点；生命归零失能，不再进入回合。能力暴走时使用能力会反噬 1 点生命。走出安全边界立即死亡，尸体随机刷回边界内，并留下一条持久的视觉世界信息。
- 行动工具：`move` / `speak` / `tell` / `attack` / `take` / `drop` / `give` / `use` / `interact` / `assist` / `ability`；每轮可以先移动再执行一个行为（意图里同时给 `moveTo` 与 `kind`），只移动时用 `kind=move`。`move` 每轮最多 6 格；目标超过 6 格时沿最短路走 6 格，BFS 自动绕开墙与其他活跃角色；目标落在墙里或被占时，先在目标附近找可走格，再按“路径长度 + 到目标距离”选最优路线，沿路走 6 格。跨层须经楼梯。定义集中在 `src/sim/tools.ts`，mock 与 LLM 提示词共用。
- 物理层：`World.items` 记录物品（地面 / 背包 / 容器三种位置），`World.fixtures` 记录设施（closed / open / locked / broken / on / off）。`take`/`drop`/`give` 搬运物品，`use` 处理药品、文件与钥匙，`interact` 处理开/关/锁/解锁/撬开容器、写黑板、开关装置；`assist` 让同伙本轮攻击 +1。
- 学园物件：阁楼档案箱（锁，内有旧校徽与信号枪）、医务室药柜（锁，内有档案钥匙）、井口（内有井底名册）、温室灌溉阀、地下室封印门；抑制药、三页抄本、总钥匙、撬棍、消防斧、防暴盾散布在角色或地图上。
- 边界：这些动作目前由模拟引擎直接执行，尚未注册为 dsh 工具；接 dsh 工具流水线需要每角色一个真实会话（P3）。
- 每轮流程：所有存活角色并行进入 feeling（空间信息候选 + 视野内人物；按通道计算感知强度，300 以上给全文、50–299 给模糊版；既无新条目也看不见人时跳过模型调用）→ thinking（0–4 条想法 + 至多一个意图 + 状态 patch）→ acting（一次写调用；意图可带 `moveTo`，先移动再执行行为）→ 结算（按先手、冲突失败、关系计数、机械漂移、patch 提交、反馈摘要）。死亡与失能者不参与。
- feel 订阅：说话等声音作为 `sound` 空间信息进入候选，并带 `sourceName`；视野内人物作为 `visible` 直接进入 feel。LLM 用 `remember` 订阅信息、用 `rememberPeople` 记住人物；被选中的在场者会写成 `seen-*` 私人记忆，思考阶段能看到。
- 感知近似：视觉走视线，声音每格 50、气味每格 100，隔墙额外损耗；空间信息过期后从所有格子消失。
- 界面：下一轮 / 自动播放，事件流，检查器显示携带物品、地面物品、设施状态、需求、态度、目标、记忆（带 provenance）与上一轮想法/行动；2D 地图用金色菱形标物品、青色方块标设施。
- 右侧面板三个页签：检查器（角色 / 格子，含该格本轮信息与本轮事件）、总览（世界指标 + 全部角色状态）、回合（每轮摘要与明细）。
- 状态回写：模型可写实体 id、姓名、常见称呼（会长 / 转校生 / 校医等），目标可写 goal id 或目标文本；引擎统一解析成实体 id 与 goal id 后落库，自指态度和无法解析的目标直接丢弃，避免脏键与无效状态。
- 回合记录：每轮保存行动（含成功/失败）、事件、本轮发射的信息、状态 patch、背包、物品与设施快照，以及异步生成的摘要；`exportLog()` 导出 JSON，供分析与复现。
- 实时落盘：每轮结束立即追加一行到 `~/.dsh/evoverse/logs/<场景>-<UTC>-r<版本>.jsonl`（可用 `EVOVERSE_LOG_DIR` 改目录）。文件是 JSONL，`session` 行记录场景与角色初始状态，`round` 行记录完整回合、角色状态、指标与用量，`summary` 行补写异步摘要；「回合」页显示当前文件路径与已写入轮数。
- 世界运行时挂在模块级，不随面板挂载/卸载销毁：未手动暂停时，切到 dsh 其他页面，自动推演与落盘继续。顶栏「重置」清空当前进度、按同一场景重开世界并新开一份日志。
- 摘要异步生成：默认模板实现（即时、可复现），`createLlmSummarizer(complete)` 已实现，等待宿主注入传输。
- 思考层可替换：`mock-mind` 只在没有宿主桥（独立开发页）时兜底；`llm-mind` 通过宿主桥调用真实模型，桥存在时所有存活角色都走 LLM。
- 提示拼装：角色的全部记忆、全部关注主题、完整反馈摘要、全部可感知候选（含声音来源）、6 步内可达格（带区域名与坐标）、目标 id、在场实体 id、背包物品与当前格物品/设施都进提示，不做位置截断（上下文预算充足）；`feel` 也不再限制候选条数。
- 模型桥：Node 半注册 `POST /evoverse/chat`，用 `ctx.llm.stream` 和插件配置（`deepseek-flash` / `low`）转发；页面启动时注入 `EVOVERSE_BRIDGE_KEY`，请求必须带 `x-evoverse-key`。桥存在时每轮所有存活角色都走 LLM（感受 + 思考 + 行动，各自最多一次），单次输出上限 2500 tokens；每轮另有 1 次异步总结。没有桥时整体回落确定性思考层。
- 用量仪表盘：按阶段（感受 / 思考 / 总结）与回合统计调用数、输入 / 输出 / 缓存 tokens 和错误数；顶栏显示累计调用与 tokens。
- 数学观测：每轮采集 10 个度量——信息势（共享信息上、按关注主题与社会通透性加权的最新说法差）、活动率、主题熵、说法熵、认知冲突、谣言穿透、共识度、空间熵、场质量、信息枢纽影响力；面板给出「信息势 × 活动」相平面、逐轮回读与自动结论（热寂 / 停滞 / 演进 / 趋同 / 分裂）。
- 开发态调试入口：`window.__evoverse`（仅 `import.meta.env.DEV`，插件打包时为 false）。
- 客户端面板包了错误边界（渲染失败显示错误页与"重新挂载"）；3D 卸载时释放 WebGL 上下文；插件热重载后若布局仍选中本面板，会自动重新选中一次。

## 打包与安装

- `package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`，`dsh.client` 声明 web 平台与依赖包；`exports` 暴露 `.` 与 `./client`。
- 客户端包用 esbuild 打成闭包工厂：three.js 打进包内，`react` / `react-dom` 走宿主模块表，CSS 内联成一次 `<style>` 注入。
- 安装：`pnpm dsh plugin --profile <name> add <仓库路径>`，profile 的 bundles 列表末尾会追加 `evoverse`；启动 `pnpm dsh --profile <name>`。
- 已验证：侧边栏入口出现、主面板替换会话区、庄园场景与 three.js 3D 可用、切回会话时面板卸载。宿主日志无报错。
