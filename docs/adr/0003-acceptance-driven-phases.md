# ADR-0003 验收驱动的阶段制推进

- 状态：已接受
- 日期：2026-10-26

## 背景

终局依赖一长串前置能力。状态模型未稳就做多 agent，会被回放不一致与因果丢失追着改地基。

## 决策

按 P0–P4 推进，每阶段单一可执行验收，不过不进入下一阶段。验收见 README 路线图。

## 候选

| 方案 | 取舍 |
|---|---|
| 阶段制 + 硬验收 | 每阶段有端到端可观察的闭环，横切关注点早期承重。接受 |
| 按模块并行开发 | 更快出代码量，集成点全推迟到最贵时刻。否决 |
| 一次做完再验收 | 赌博。否决 |

## 后果

- 正：失败范围限制在单阶段内；可解释性从 P1 承重。
- 负：存在为验收而做的临时实现（如 P1 先用内存编年史），须在 open-questions 登记替换阶段。
