# ADR-0007 回合制并发执行

- 状态：已接受
- 日期：2026-10-26
- 相关：T1 / G3 / D5；取代 ADR-0004 第 5 条

## 背景

角色需要同时行动。逐事件推进无法定义"同一时刻"；而即时生效的并发是伪并发——后行动者能看到先行动者的结果。

## 决策

- **一轮 = 并发宣告 + 统一结算**。角色基于轮初快照行动，效果在结算时统一应用。
- **回合不是时钟**：只有存在愿意行动的角色时才开启下一轮；无人行动，世界停止。
- **结算顺序确定**：按行动优先级排序，同值按 id。同一目标的不兼容行动在结算时裁决，不额外调用模型。
- **信息在结算后可见**：第 N 轮说出的话在第 N+1 轮被感知。
- **TTL 以回合为单位**：1 回合 = 存活到下一轮结算前。

## 候选

| 方案 | 取舍 |
|---|---|
| 事件队列 + 静止点 | 无明确边界，"同一时刻"不可定义，并发语义模糊。否决（取代 ADR-0004 第 5 条） |
| 即时生效的并发 | 先到先得，因果被人为串行化。否决 |
| 回合制并发 | 并发有真实语义，边界清晰，回放以回合为单位。接受 |

## 后果

- 正：每轮一个快照、一个哈希，回放与校验单位明确；"同时发生"可以被表达和解释。
- 负：一轮耗时等于最慢角色的延迟（尾延迟），需要超时策略；不下场的角色若无法廉价判定，成本会按角色数线性增长。
- 待定：迟到角色的行动推迟还是丢弃；行动优先级是否作为角色状态字段。
